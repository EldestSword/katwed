# Literal Band Names 2 — Harder

This folder contains the optional cover and 20 question images for the harder
Literal Band Names quiz pack. Files are numbered in quiz order and are 16:9
PNG images suitable for manual upload through the Katwed quiz editor.

The visual set uses a consistent colourful 3D editorial style with playful
surrealism, tactile materials and cinematic teal, violet, coral and gold
lighting. Question images deliberately contain no readable titles, logos,
album artwork, band members or interface elements.
