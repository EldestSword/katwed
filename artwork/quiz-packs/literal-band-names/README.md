# Literal Band Names image pack

This folder contains the cover and twenty 16:9 question images for the imported **Literal Band Names** quiz.

- `00-cover.webp` is the optional quiz cover.
- Files `01-*.webp` through `20-*.webp` match the quiz question order exactly.
- Every image is 1600 × 900 WebP and is ready for Katwed's existing image uploader.
- The question images contain no readable answer text, band logos, album covers or interface elements.

To attach them manually, open the quiz editor, choose each numbered question, replace its uploaded image with the matching numbered file, choose the cover from Quiz settings, then save the quiz once after all uploads finish.
