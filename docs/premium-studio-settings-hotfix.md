# Premium Studio settings hotfix

This focused hotfix completes the Quiz Settings portion of the premium Studio pass.

- Quiz Settings now opens on Themes rather than Game.
- Six dedicated sections are exposed: Themes, Backgrounds, Answer colours, Cover, Game and People bank.
- The existing full Theme Browser is given its own primary workspace.
- Backgrounds and cover no longer share one long Appearance panel.
- People bank moves out of the per-question sidebar into quiz-wide settings.
- Existing save, validation, theme/background compatibility, Head-to-Head and cover-upload behaviour is unchanged.
- Desktop and mobile layout polish is scoped to the host Studio settings modal.
