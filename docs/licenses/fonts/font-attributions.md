# Theme font licences and attribution

All redistributed fonts are installed through Fontsource 5.3.0 from Google Fonts upstream sources and shipped only as the listed Latin WOFF2 file. The System UI entry redistributes no file. The full [SIL Open Font License 1.1](OFL-1.1.txt) and [Apache License 2.0](Apache-2.0.txt) texts are stored in this directory; each installed package also retains its upstream `LICENSE` in development dependencies.
